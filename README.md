<h1 align="center">💡 Сайт для создания API </h1>

<p align="center">
  <b>Secret</b> — это инструмент для помощи и автоматического создания API к различным сайтам и ресурсам с помощью парсинга и анализа кода
  <br>
  Особенно полезен, если сайт не предоставляет официальный API ✨
</p>

---

## ⚙️ Функционал сайта

- 🔍 Парсинг сайта  
- 🌐 Просмотр потоков ресурса / сайта  
- 🧠 Анализ кода и сетевых запросов  
- 🎧 Получение медиа (аудио / видео)  
- ⚡ Создание простого API
