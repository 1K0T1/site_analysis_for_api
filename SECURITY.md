# Security Policy

## Supported Versions

| Version | Supported         |
| ------- | ----------------- |
| 0.5.x   |  ✅              |
| 0.4.x   |  ⚠️              |
| 0.3.x   | ❌               |

## Reporting a Vulnerability

Рекомендуется использовать последнюю стабильную версию Secret для максимальной безопасности и совместимости.
